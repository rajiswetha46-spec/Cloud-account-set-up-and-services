# Theory

Amazon Web Services (AWS) is the world's leading cloud computing platform developed by Amazon. Instead of purchasing expensive servers, organizations can rent computing resources over the internet.

AWS provides more than 200 cloud services, including:

- Computing
- Storage
- Databases
- Networking
- Artificial Intelligence
- Machine Learning
- Security
- Analytics

AWS follows a Pay-As-You-Go pricing model, where users pay only for the resources they use.

---

# Advantages

- No hardware purchase required
- Highly scalable
- Secure
- Reliable
- Global availability
- Cost effective

# Procedure

## Step 1

Open your web browser and visit:

```
https://aws.amazon.com
```

## Step 2

Click **Create an AWS Account**.

## Step 3

Enter the following details:

- Email Address
- Password
- AWS Account Name

Click **Continue**.

## Step 4

Choose **Personal Account**.

(Students can also choose Business Account if instructed.)

## Step 5

Enter:

- Name
- Address
- Phone Number

Accept the AWS Customer Agreement.

## Step 6

Enter your Debit/Credit Card details for identity verification.

*A small temporary verification charge may be applied and later reversed.*

## Step 7

Verify your mobile number using the OTP.

## Step 8

Select **Basic Support (Free)**.

## Step 9

Log in to the AWS Management Console.

# AWS Services Explored

## EC2

Virtual servers in the cloud.

## S3

Cloud object storage service.

## IAM

Identity and Access Management for users and permissions.

## VPC

Virtual Private Cloud for AWS resources.

## RDS

Managed Relational Database Service.

## Lambda

Run code without managing servers.

## CloudWatch

Monitoring and logging service.

## SNS

Simple Notification Service for sending notifications.
